A sleek, modern web app that generates creative social media captions using AI. Just drop your idea, pick a vibe, and let the AI do the magic.

---

## ✨ Features

- 🔥 **Viral / Edgy** — Trendy captions for Instagram & TikTok
- 💼 **Corporate / LinkedIn** — Professional captions for LinkedIn
- ✨ **Minimalist / Aesthetic** — Short, clean captions
- 🌙 **Dark / Light Mode** toggle
- 📋 **Copy to Clipboard** with one click
- ⚡ Powered by OpenRouter AI (free tier)

---

## 🛠️ Tech Stack

- **Frontend:** HTML, Tailwind CSS, Vanilla JavaScript
- **AI API:** OpenRouter (free models)
- **Local Server:** Laragon

---

## 🚀 Getting Started

### 1. Clone the repo
```bash
git clone https://github.com/Ali-developer20/Caption-Generator.git
cd Caption-Generator
```

### 2. Get a free API key
- Go to [openrouter.ai](https://openrouter.ai)
- Sign up and create a free API key

### 3. Create your config file
Create a file called `config.js` in the project root:
```js
const CONFIG = {
    API_KEY: "your-openrouter-api-key-here"
};
```

### 4. Run the project
- Open with **Laragon** or any local server
- Visit `http://localhost/Caption-Generator/`
